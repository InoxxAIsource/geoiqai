BUG 1: SCORE FORMULA WRONG
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

wikipedia.org has 6M mentions, 892 citations 
but scores only 40/100. Formula is wrong.

Replace current score formula with this:

const mentions   = totalMentions     // e.g. 6,000,000
const citations  = totalCitations    // e.g. 892
const citedPages = totalCitedPages   // e.g. 10

// Mention score: log scale so large domains 
// don't max out but small ones still score
const mentionScore = Math.min(
  Math.log10(Math.max(mentions, 1)) / Math.log10(10000000) * 40, 
  40
)

// Citation score: ratio of citations to mentions
// Wikipedia: 892/6M = 0.015% which is normal
// Scale so 0.01%+ = good score
const citationRatio = citations / Math.max(mentions, 1)
const citationScore = Math.min(
  Math.log10(Math.max(citationRatio * 100000, 1)) / 5 * 40,
  40
)

// Page score
const pageScore = Math.min(citedPages / 50 * 20, 20)

const score = Math.min(100, Math.round(
  mentionScore + citationScore + pageScore
))

Expected results with this formula:
- wikipedia.org (6M mentions, 892 citations): ~85-90
- primevideo.com (1.6M mentions, low citations): ~65-70
- namecheap.com (27K mentions, 0 citations): ~35-40
- geoiqai.com (small, new): ~5-15

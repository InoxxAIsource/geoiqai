Before every DataForSEO call check cache:

table: dataforseo_cache
columns: cache_key, response_json, 
  endpoint, cached_at, domain

Cache duration per endpoint:
SERP results: 24 hours
On-Page audit: 48 hours
Brand mentions SERP: 24 hours

const getCached = async (key) => {
  const { data } = await supabase
    .from('dataforseo_cache')
    .select('*')
    .eq('cache_key', key)
    .gt('cached_at', 
      new Date(Date.now() - CACHE_DURATION).toISOString()
    )
    .single();
  return data?.response_json || null;
};

const setCache = async (key, data, endpoint, domain) => {
  await supabase.from('dataforseo_cache').upsert({
    cache_key: key,
    response_json: data,
    endpoint,
    domain,
    cached_at: new Date().toISOString()
  });
};

Cache key format:
`${endpoint}_${domain}_${keyword}_${date}`
e.g. "serp_clevertap.com_mobile_marketing_2026-06-07"

Show in UI when data is from cache:
Small grey badge: "Data from 3 hours ago [Refresh]"

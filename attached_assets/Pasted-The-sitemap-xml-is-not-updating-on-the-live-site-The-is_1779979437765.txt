STEP 2: Serve sitemap.xml dynamically from the
API server instead of as a static file.

In artifacts/api-server/src/routes/index.ts
add this route BEFORE the static file middleware:

app.get('/sitemap.xml', (req, res) => {
  res.setHeader('Content-Type', 'text/xml');
  res.setHeader('Cache-Control', 'no-cache');
  res.sendFile(path.join(__dirname, 
    '../../../../artifacts/geoscore/public/sitemap.xml'));
});

This ensures the API server always serves the 
latest version of the sitemap file directly,
bypassing any CDN or build cache.

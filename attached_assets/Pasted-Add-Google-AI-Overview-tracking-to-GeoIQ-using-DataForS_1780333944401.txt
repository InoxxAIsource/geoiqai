Add Google AI Overview tracking to GeoIQ 
using DataForSEO SERP API.

Currently Google AI Overview shows 
"estimated" or is not tracked with 
real data. Fix this completely.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1 — Add DataForSEO SERP API call 
for Google AI Overview

For each domain audit, after running 
the existing AI system checks, add 
a Google AI Overview check.

Use the domain's top 3 tracked keywords 
or prompts (same ones used for 
LLM Scraper calls).

For each keyword call:

POST https://api.dataforseo.com/v3/serp/
google/organic/live/advanced

Headers:
Authorization: Basic [existing DataForSEO 
credentials already in env]
Content-Type: application/json

Body:
[
 {
   "keyword": "[tracked keyword]",
   "location_code": 2840,
   "language_code": "en",
   "device": "desktop",
   "os": "windows",
   "depth": 10
 }
]

Cost: $0.002 per call
3 keywords = $0.006 per audit
Negligible cost.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2 — Parse the AI Overview response

From the response parse items array 
and look for these element types:

Primary: type = "ai_overview"
Fallback: type = "featured_snippet"

For ai_overview element extract:
- text: the full AI Overview answer text
- items: cited source URLs and titles
- asker: the question Google answered

Example response structure:
{
 "type": "ai_overview",
 "text": "GeoIQ is an AI visibility 
 platform that tracks...",
 "items": [
   {
     "type": "ai_overview_element",
     "title": "GeoIQ - AI Visibility",
     "url": "https://geoiqai.com",
     "domain": "geoiqai.com"
   }
 ]
}

Brand detection logic:
const brandMentioned = 
 aiOverviewText.toLowerCase()
 .includes(brandName.toLowerCase())
 ||
 aiOverviewItems.some(item => 
   item.domain === auditedDomain
 )

Score calculation:
If brand mentioned in text AND 
domain in cited sources: 100/100
If brand mentioned in text only: 70/100
If domain in cited sources only: 50/100
If AI Overview exists but brand 
not mentioned: 20/100
If no AI Overview found for keyword: 0/100

Final Google AI Overview score = 
average across 3 keywords

STEP 6 — Add Fix Recommendations

If brand not in Google AI Overview 
add these specific fix actions:

FIX A — If AI Overview exists 
but brand not cited:

Title: Get cited in Google AI Overview

Why: Google AI Overview cites 3-5 sources 
directly. Appearing here drives zero-click 
visibility for millions of searches.

How:
Step 1. Identify which sources Google 
is currently citing for this keyword
(shown in cited_sources above)
Step 2. Get featured or mentioned on 
those exact domains
Step 3. Add FAQ schema to your homepage 
answering the exact question Google 
AI is responding to
Step 4. Rewrite your answer page with 
the answer in the first 150 words
Step 5. Rescan in 2 weeks

Score impact: +25 points
Effort: 1 week
Priority: High

FIX B — If no AI Overview found:

Title: Create content to trigger 
Google AI Overview

Why: Google AI Overview only appears 
for queries with clear informational 
intent. Creating the right content 
can trigger AI Overview for your 
category keywords.

How:
Step 1. Identify question-format 
keywords in your category
Step 2. Create a dedicated FAQ or 
guide page answering that question
Step 3. Add FAQPage schema markup
Step 4. Ensure answer appears in 
first 150 words of the page
Step 5. Build 3-5 backlinks to that page

Score impact: +15 points
Effort: 2-3 weeks
Priority: Medium

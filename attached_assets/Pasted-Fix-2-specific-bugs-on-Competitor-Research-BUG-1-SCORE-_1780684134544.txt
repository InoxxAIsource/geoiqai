BUG 2: STRONG = 0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Strong shows 0. Looking at the table:
- "yankee" shows netflix 7.5M, primevideo "-"
  This should be UNIQUE not Strong

- "streaming services" shows both 4.1M each
  This is correctly SHARED

Strong should be: YOU appear AND competitor 
appears BUT you have significantly more volume.

None of the current 155 topics qualify as Strong
because when both appear, volumes are equal (4.1M).

This is because DataForSEO returns same 
ai_search_volume for both brands on shared topics
— the volume is for the topic, not per-brand.

Fix Strong classification using search result 
RANK POSITION as proxy for strength:

// Your topic appears at rank 5, competitor at rank 50
// = you are stronger on this topic

const yourRankMap = {}
yourTopics.forEach((t, idx) => {
  const key = (t.se_query||t.question||t.keyword||'')
    .toLowerCase().trim()
  yourRankMap[key] = idx + 1  // 1-based rank
})

const compRankMap = {}
competitorTopics.forEach((t, idx) => {
  const key = (t.se_query||t.question||t.keyword||'')
    .toLowerCase().trim()
  compRankMap[key] = idx + 1
})

allTopics.forEach(topic => {
  const key = topic.topic.toLowerCase().trim()
  const yr = yourRankMap[key] || 9999
  const cr = compRankMap[key] || 9999

  if (yr < 9999 && cr === 9999) {
    topic.status = 'unique'    // only you
  } else if (yr === 9999 && cr < 9999) {
    topic.status = 'missing'   // only competitor
  } else if (yr < cr * 0.6) {
    topic.status = 'strong'    // you rank much higher
  } else if (cr < yr * 0.6) {
    topic.status = 'weak'      // competitor ranks much higher
  } else {
    topic.status = 'shared'    // roughly equal rank
  }
})

With 100 topics from each brand:
- Topics ranked 1-30 in yours but not in 
  competitor top 100 = unique
- Topics ranked 1-30 in competitor but not 
  in your top 100 = missing  
- Topics in both but your rank much better = strong
- Topics in both but competitor rank much better = weak

This should give Strong > 0.

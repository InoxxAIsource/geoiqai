FIX 1 — Store real citation data from 
DataForSEO LLM Scraper response

After every LLM Scraper API call, 
parse and store the results in Supabase.

Create a new Supabase table called 
citation_sources with these columns:

id: uuid primary key
user_id: uuid (current user)
audited_domain: text (domain being audited)
source_url: text (full URL from search_results)
source_domain: text (domain extracted from URL)
citation_type: text (authority/social/brand/competitor)
prompt_used: text (which prompt triggered this)
ai_system: text (chatgpt/perplexity/gemini)
appeared_in_response: boolean (was brand mentioned)
timestamp: timestamptz

After every LLM Scraper call:

const items = response.tasks[0].result[0].items

for (const item of items) {
  
  // Store search_results
  if (item.search_results) {
    for (const result of item.search_results) {
      await supabase
        .from('citation_sources')
        .insert({
          user_id: currentUserId,
          audited_domain: domain,
          source_url: result.url,
          source_domain: extractDomain(result.url),
          citation_type: classifyDomain(result.url),
          prompt_used: currentPrompt,
          ai_system: 'chatgpt',
          appeared_in_response: 
            item.brand_entities?.includes(brandName),
          timestamp: new Date().toISOString()
        })
    }
  }

  // Store sources separately
  if (item.sources) {
    for (const source of item.sources) {
      await supabase
        .from('citation_sources')
        .insert({
          user_id: currentUserId,
          audited_domain: domain,
          source_url: source.url,
          source_domain: source.domain,
          citation_type: classifyDomain(source.url),
          prompt_used: currentPrompt,
          ai_system: 'chatgpt',
          appeared_in_response: 
            item.brand_entities?.includes(brandName),
          timestamp: new Date().toISOString()
        })
    }
  }
}

classifyDomain() function:
social domains (twitter, linkedin, 
facebook, instagram) → "social"
brand's own domain → "brand"  
competitor domains → "competitor"
everything else → "authority"

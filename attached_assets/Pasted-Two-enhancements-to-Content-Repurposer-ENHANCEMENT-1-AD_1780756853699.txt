ENHANCEMENT 2: CLEAN CONTENT FORMATTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Claude returns content with:
- Dashes at line starts (- item)
- Em dashes (—)
- Markdown headers (## Heading, # Title)
- Bold markers (**text**)
- Asterisks (*text*)

Fix in TWO places:

PLACE 1: Claude system prompt — add this line:
"Never use dashes, em dashes, markdown headers, 
asterisks, or bullet points in any content field. 
Use plain sentences and line breaks only. 
For lists, write each item on its own line 
with no prefix character."

PLACE 2: Frontend sanitizer — run on every 
content field before displaying:

const cleanContent = (text) => {
  if (!text) return '';
  return text
    .replace(/^#{1,6}\s+/gm, '')        // ## headers
    .replace(/\*\*(.*?)\*\*/g, '$1')    // **bold**
    .replace(/\*(.*?)\*/g, '$1')        // *italic*
    .replace(/^[-–—]\s+/gm, '')         // - bullets
    .replace(/^•\s+/gm, '')             // • bullets  
    .replace(/—/g, ' ')                 // em dash
    .replace(/–/g, ' ')                 // en dash
    .replace(/`(.*?)`/g, '$1')          // `code`
    .trim();
};

Apply cleanContent() to ALL text fields 
before rendering in cards:
content, hook, title, subtitle, 
first_comment, comment — every field.

Also apply to Twitter tweets array:
tweets: data.tweets.map(t => cleanContent(t))
